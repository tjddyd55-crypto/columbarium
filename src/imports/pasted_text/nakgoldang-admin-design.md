프로젝트명: 낙골당 분양 플랫폼 관리자 웹 (Admin Dashboard)

목표:
사업자(OPERATOR_ADMIN)와 슈퍼관리자(SUPER_ADMIN)가 사용하는 관리 웹 UI를 설계한다.
데이터 관리, 빠른 조회, 효율적인 운영이 핵심이며, 복잡한 기능을 직관적으로 처리할 수 있도록 구성한다.

========================
1. 전체 디자인 컨셉
========================

- 스타일: SaaS Admin Dashboard (Stripe + Notion + Toss Admin 느낌)
- 톤: 깔끔, 효율적, 데이터 중심
- 컬러:
  - Primary: 네이비 (#1E293B)
  - Secondary: 블루 (#3B82F6)
  - Background: 밝은 회색 (#F9FAFB)
  - Border: #E5E7EB

- 폰트:
  - Inter 또는 Pretendard

- 레이아웃:
  - 좌측 사이드바 + 상단 헤더

========================
2. 전체 레이아웃
========================

좌측 사이드바 (고정):

메뉴:
- 대시보드
- 사업자 관리 (슈퍼관리자만)
- 시설 관리
- 좌석(칸) 관리
- 대기열 관리
- 계약 관리
- 재판매 관리
- 회원 관리
- 알림 관리
- 감사로그

상단 헤더:
- 페이지 타이틀
- 검색창
- 사용자 프로필

========================
3. 대시보드 화면
========================

구성:

상단 KPI 카드 4개:
- 총 시설 수
- 총 계약 수
- 활성 대기열 수
- 오늘 계약 수

중간:
- 최근 계약 리스트 (테이블)
- 최근 알림/이벤트

하단:
- 상태 통계 (차트)

========================
4. 공통 테이블 디자인
========================

테이블 필수 요소:

- 컬럼 정렬 가능
- 검색
- 필터
- 페이지네이션
- 상태 배지

상태 색상:
- ACTIVE → 초록
- PENDING → 노랑
- FAILED → 빨강
- COMPLETED → 파랑

행 hover 효과 적용

========================
5. 사업자 관리 화면
========================

테이블:
- 사업자명
- 사업자번호
- 상태
- 생성일

기능:
- 추가
- 수정
- 활성/비활성

6. 시설 관리 화면

컬럼:

- row
- col
- price
- status

기능:

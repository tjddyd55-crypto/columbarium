# 권한 정책표

## 역할 정의

| 역할 | 코드 | 설명 |
|------|------|------|
| 슈퍼관리자 | SUPER_ADMIN | 플랫폼 전체 운영, 모든 사업자/시설/계약/회원 관리 |
| 업체관리자 | OPERATOR_ADMIN | 소속 사업자 내 시설·계약·재판매·대기열·회원 관리 |
| 영업관리자 | SALES_MANAGER | 추천 링크/코드, 내 추천 고객, 계약 진행, 수수료 조회 |
| 일반 사용자 | USER | 시설 조회, 대기열, 계약, 재판매 신청, 마이페이지 |

## 데이터 범위

- **SUPER_ADMIN**: operator_id 무관, 전체 데이터.
- **OPERATOR_ADMIN**: `operator_id IN (본인이 관리자로 소속된 사업자)`.
- **SALES_MANAGER**: 조회 시 본인 `partner_id` 귀속 건 + 소속 operator 범위(정책에 따라).
- **USER**: 본인 `user_id` 데이터만.

---

## API·리소스 접근

- 인증 필수 구간: JWT 검증 후 `role`로 Guard 적용.
- 리소스 단위: URL 또는 body의 `operator_id`, `facility_id`, `user_id`가 현재 사용자 권한 범위 내인지 검사.
- 슈퍼관리자만 `/admin/*` 일부 경로 허용. 업체관리자/영업은 `/operator/*` 등 역할별 prefix 분리 권장.

# 관리자 웹 IA 및 화면 구조

## 1. 개요

- **대상**: 업체관리자(OPERATOR_ADMIN), 슈퍼관리자(SUPER_ADMIN).
- **원칙**: PC 대응 대시보드, 모바일도 일부 사용 가능. UX 기준은 모바일 우선이지만 관리자 구역은 PC 편의 우선.

---

## 2. 업체관리자(OPERATOR_ADMIN)

### 2.1 메인 메뉴 (사이드/상단)

```
대시보드 | 시설 관리 | 좌석/배치 관리 | 가격 관리 | 분양/계약 관리 | 재판매 승인 | 대기열 현황 | 회원 관리 | 알림 관리
```

### 2.2 화면 트리

```
[대시보드]
├── 요약 (시설 수, 대기열 수, 당월 계약, 재판매 대기 건 등)
└── 최근 활동

[시설 관리]
├── 내 시설 목록
├── 시설 등록
└── 시설 상세/수정
    ├── 기본 정보 (이름, 주소, 지도, 연락처, 소개, 운영시간)
    └── 건물/층/구역 구조

[좌석/배치 관리]
├── 시설 선택
├── 건물/층/구역 CRUD
├── 배치도 등록/수정 (이미지, 스케일)
├── 칸(unit) 목록
├── 칸 일괄 생성/수정
├── 칸 상태 변경 (AVAILABLE, BLOCKED 등)
└── 좌표(x,y,width,height) 편집

[가격 관리]
├── 시설/구역별 분양가·선분양가
└── 칸 단위 가격 수정

[분양/계약 관리]
├── 계약 목록 (필터: 시설, 상태, 기간)
├── 계약 상세
└── (필요 시) 계약 상태 변경

[재판매 승인]
├── 재판매 신청 목록 (REQUESTED 등)
├── 상세 (계약 정보, 희망가, 매도자)
├── [승인] / [반려]
└── 승인 후 LISTED 등 상태 관리

[대기열 현황]
├── 시설/칸별 대기열 목록
├── 순번, 사용자, 상태(WAITING/ACTIVE/EXPIRED)
└── ACTIVE 만료·승격 이력 확인

[회원 관리]
├── (소속 시설 관련) 회원 목록/검색
└── 상세 (계약, 대기열, 재판매)

[알림 관리]
├── 발송 이력
└── (정책에 따라) 수동 발송/템플릿
```

## 3. 슈퍼관리자(SUPER_ADMIN)

### 3.1 메인 메뉴

```
전체 대시보드 | 사업자 관리 | 시설 관리 | 계약 관리 | 재판매 관리 | 회원 관리 | 영업관리자 관리 | 알림/운영 설정 | 통계/리포트
```

### 3.2 화면 트리

```
[전체 대시보드]
├── 플랫폼 요약 (사업자 수, 시설 수, 계약 수, 대기열 수)
├── 사업자별 요약
└── 최근 계약/재판매

[사업자 관리]
├── 사업자 목록
├── 사업자 등록
└── 사업자 상세/수정
    ├── 기본 정보
    └── 업체관리자(operator_admins) 지정

[시설 관리]
├── 전체 시설 목록 (사업자 필터)
└── 시설 상세 (읽기/수정 권한에 따라)

[계약 관리]
├── 전체 계약 목록
├── 필터 (사업자, 시설, 기간, 상태)
└── 계약 상세

[재판매 관리]
├── 전체 재판매 목록
└── 상세/승인 (업체와 동일 플로우, 범위만 전체)

[회원 관리]
├── 전체 회원 목록/검색
└── 회원 상세 (역할, 계약, 대기열, 로그인 이력 등)

[영업관리자 관리]
├── 영업관리자(partner_profiles) 목록
├── 소속 사업자 지정
├── 추천코드/링크 조회
└── 비활성화/활성화

[알림/운영 설정]
├── 알림 템플릿
├── 발송 채널 (푸시, SMS, 이메일) 설정
└── 대기열 알림 정책 (7일/1일/ACTIVE)

[통계/리포트]
├── 사업자별·시설별 계약/매출
├── 대기열 통계
└── 재판매 통계
```

---

## 4. 공통 레이아웃

- **헤더**: 로고, 사업자/시설 선택(업체관리자), 알림, 로그아웃.
- **사이드 내비**: 역할에 따라 메뉴 노출 구분 (슈퍼: 전체 메뉴, 업체: 소속 관련만).
- **테이블/필터**: PC에서 리스트·필터·정렬·페이징.
- **폼**: 시설/칸/가격 등 긴 폼은 단계별 또는 탭 분리.

---

## 5. 접근 제어

- 로그인 후 `role`에 따라 메뉴·라우트 제한.
- 슈퍼: `/admin/*` 전체. 업체: `/operator/*` 및 본인 `operator_id` 범위만.
- API에서 동일 권한 검사 적용.

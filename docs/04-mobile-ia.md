# 모바일 앱 IA 및 화면 구조

## 1. 정보 구조(IA) 개요

- **대상**: 일반 사용자(USER), 영업관리자(SALES_MANAGER).
- **원칙**: 모바일 앱 우선 UX, 한국 서비스, 네이버 지도·소셜/휴대폰 인증 전제 설계.

---

## 2. 공통/인증 (역할 무관)

```
[공통]
├── 스플래시
├── 로그인
│   ├── 일반 로그인
│   ├── 네이버 로그인
│   └── 카카오 로그인
├── 회원가입
│   ├── 약관 동의
│   ├── 필수 정보 입력 (아이디, 비밀번호, 이름, 생년월일, 연락처, 이메일, 주소)
│   └── 휴대폰 인증
├── 휴대폰 인증 (인증번호 입력)
├── 비밀번호 찾기 / 재설정
├── 주소 입력 (검색 → 선택)
└── (로그인 후) 역할에 따라 홈 분기
```

---

## 3. 일반 사용자(USER) 앱

### 3.1 탭/메인 메뉴

```
[하단 탭]
  홈 | 시설검색 | 대기열 | 내 계약 | 마이페이지
```

### 3.2 화면 트리

```
[홈]
├── 추천 시설
├── 인기 시설
├── 최근 등록 시설
├── 대기열 많은 인기 위치
└── 검색바 → 시설 리스트로 이동

[시설검색 / 리스트]
├── 필터: 지역, 가격, 분양가능, 선분양, 재판매
├── 지도 보기 / 리스트 보기 전환
└── 카드 탭 → 시설 상세

[시설 상세]
├── 이미지, 소개
├── 위치 (네이버 지도)
├── 가격 정보, 선분양 여부
├── 대기열 현황
└── [층/구역 선택] → 좌석(배치도)

[좌석/배치도]
├── 줌/드래그 (좌표 기반, 상태별 색상)
├── 칸 선택 → 바텀시트 (상세, 대기 수)
├── [대기열 참여]
└── (이미 대기 중) 대기열 상세로 이동

[대기열 상세]
├── 내 순번, 앞 대기자 수
├── 예상 시점
├── 알림 설정 상태
└── [대기 취소]

[ACTIVE 구매 기회] (순번 도달 시)
├── 24시간 카운트다운
├── 가격/조건 표시
└── [계약 진행]

[계약 진행]
├── 회원 정보 자동 채움
├── 추천코드 입력
├── 약관/계약서 확인
├── 전자서명 placeholder
└── 결제 상태 진행 (mock → 완료)

[내 계약]
├── 계약 목록
├── 계약 상세
│   ├── 납골 위치 정보
│   ├── 계약 문서
│   └── [재판매 신청]
└── 재판매 신청
    ├── 현재 계약 정보
    ├── 희망 판매가 입력
    ├── 신청 사유(선택)
    └── 안내 문구

[마이페이지]
├── 내 정보 수정 (이름, 연락처, 이메일, 주소)
├── 휴대폰/이메일 수정 (재인증 플로우)
├── 알림 설정
└── 로그아웃
```

## 4. 영업관리자(SALES_MANAGER) 앱

### 4.1 탭/메인 메뉴

```
[하단 탭]
  홈 | 내 추천 | 고객 현황 | 계약 진행 | 수수료/정산 | 마이페이지
```

### 4.2 화면 트리

```
[홈]
└── 요약 (추천 수, 진행 중 계약, 오늘 알림 등)

[내 추천]
├── 추천 링크 발급/복사
├── 추천코드 발급/복사
└── (선택) QR 코드

[고객 현황]
├── 내 추천 고객 리스트
├── 고객별 대기열/계약 상태
└── 고객 상세

[계약 진행]
├── 진행 중 계약 목록
└── 계약 상세 (상태, 결제, 서명)

[수수료/정산]
├── 수수료 대상 계약 목록
├── 건별 수수료
└── (정책에 따라) 정산 요약

[마이페이지]
├── 프로필
├── 알림 설정
└── 로그아웃
```

---

## 5. 화면 흐름 요약

| 사용자 | 진입 | 핵심 플로우 |
|--------|------|-------------|
| USER | 홈/시설검색 | 시설 상세 → 좌석 선택 → 대기열 참여 → (순번 도달) ACTIVE → 계약 → 내 계약 / 재판매 신청 |
| SALES_MANAGER | 내 추천 | 링크/코드 공유 → 고객 현황 → 계약 진행/수수료 확인 |

---

## 6. 공통 컴포넌트·UX

- **지도**: 네이버 지도, 시설 위치 마커, 상세에서 풀스크린 가능.
- **배치도**: 좌표 기반 렌더링, 핀치 줌/드래그, 상태별 색상(예: AVAILABLE, WAITING_QUEUE, ACTIVE_OFFER, CONTRACTED, RESALE_LISTED, BLOCKED).
- **바텀시트**: 칸 선택 시 상세, CTA(대기열 참여 등).
- **알림**: 7일 전 / 1일 전 / ACTIVE 즉시 → 푸시·앱 내 배지/리스트 연동.

프로젝트명: 봉안당 분양 플랫폼 (Korea Memorial Platform)

목표:
한국 사용자 대상의 봉안당 분양/대기열/재판매 플랫폼 모바일 앱 UI를 설계한다.
앱은 직관적이고 신뢰감 있는 금융/부동산 느낌을 가져야 하며, 중장년층도 쉽게 사용할 수 있어야 한다.

========================
1. 전체 디자인 컨셉
========================

- 스타일: 한국형 금융앱 + 부동산앱 (토스 + 직방 느낌)
- 톤: 신뢰, 안정, 차분
- 컬러:
  - Primary: 딥 블루 (#1E3A8A)
  - Secondary: 그레이 (#6B7280)
  - Background: 화이트 (#FFFFFF)
  - Accent: 골드/베이지 (프리미엄 느낌)

- 폰트:
  - Pretendard 또는 Noto Sans KR
- 버튼:
  - 크고 명확하게 (중장년층 고려)
- 간격:
  - 여유 있는 spacing (답답함 제거)

========================
2. 앱 구조
========================

하단 탭 5개 구성:

1. 홈
2. 시설검색
3. 내 대기열
4. 내 계약
5. 마이페이지

========================
3. 화면 설계
========================

------------------------
[1] 로그인 화면
------------------------

구성:
- 로고
- 아이디 입력
- 비밀번호 입력
- 로그인 버튼
- 카카오 로그인 버튼
- 네이버 로그인 버튼
- 회원가입 버튼

디자인:
- 중앙 정렬
- 버튼 큼직하게

------------------------
[2] 회원가입 화면
------------------------

입력 필드:
- 아이디
- 비밀번호
- 이름
- 생년월일
- 연락처
- 이메일
- 주소

UX:
- 단계형 or 스크롤형

------------------------
[3] 홈 화면
------------------------

구성:
- 상단 검색바
- 추천 봉안당 카드 (horizontal scroll)
- 인기 시설 리스트
- 배너 (선분양 안내)

카드 구성:
- 시설 이미지
- 이름
- 위치
- 가격대

------------------------
[4] 시설 리스트 화면
------------------------

구성:
- 필터 (지역, 가격)
- 카드 리스트

카드:
- 썸네일
- 시설명
- 위치
- 가격

------------------------
[5] 시설 상세 화면
------------------------

구성:
- 상단 이미지
- 시설 정보
- 위치 지도 영역
- 가격 정보
- “좌석 선택하기” 버튼

------------------------
[6] 좌석 선택 화면 (핵심)
------------------------

영화 좌석 UI처럼 구성

Grid 형태:

각 칸 상태 색상:
- AVAILABLE → 초록
- WAITING → 노랑
- ACTIVE → 주황
- SOLD → 빨강

클릭 시:
- 팝업:
  - 위치 (A-12)
  - 가격
  - 대기 인원
  - 버튼: “대기열 참여”

------------------------
[7] 대기열 화면
------------------------

구성:
- 내가 신청한 리스트

카드:
- 시설명
- 위치
- 내 순번
- 상태

------------------------
[8] 대기열 상세
------------------------

구성:
- 내 순번 강조
- 앞 대기 수
- 예상 안내
- 상태 표시

ACTIVE일 경우:
- 타이머 (24시간)
- “계약하기” 버튼

------------------------
[9] 계약 화면
------------------------

구성:
- 선택 좌석 정보
- 가격 정보
- 사용자 정보
- 계약 버튼

------------------------
[10] 마이페이지
------------------------

구성:
- 내 정보
- 내 계약 목록
- 내 대기열
- 로그아웃

========================
4. 컴포넌트 스타일
========================

카드:
- border-radius 16px
- 그림자 약하게

버튼:
- height: 48~56px
- radius: 12px

텍스트:
- 제목: 18~22px
- 본문: 14~16px

========================
5. UX 포인트
========================

- 복잡한 설명 제거
- 큰 버튼
- 클릭 영역 넓게
- 상태 색상 명확히
- 숫자(순번, 가격) 강조

========================
6. 추가 요구사항
========================

- 모바일 기준 (iPhone 14 사이즈)
- 컴포넌트화 (재사용 가능)
- 모든 화면 연결된 프로토타입 생성
- 실제 앱처럼 자연스럽게 이동 가능하도록 설계

========================
7. 결과물 요구
========================

다음 화면 모두 생성:

- 로그인
- 회원가입
- 홈
- 리스트
- 상세
- 좌석 선택
- 대기열
- 계약
- 마이페이지

각 화면은 실제 앱 수준으로 완성도 있게 디자인한다.
